# Design review

Run after implementation and before packaging.

Capture the full page at approximately 1440px desktop, 768px tablet, and 390px mobile. Inspect hierarchy, spacing rhythm, line length, image crops, contrast, CTA consistency, form legibility, sticky/floating controls, overflow, section repetition, and the initial viewport. Verify the logo and favicon are local assets. Fix all verified issues in one bounded batch, rebuild, and perform one confirmation pass. Record before/after evidence and unresolved limitations in `QA-REPORT.md`. Never claim visual verification without screenshots or equivalent browser evidence.
