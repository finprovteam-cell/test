# Browser verification

Use an available browser automation tool. If none exists, state that limitation and provide a manual test list instead of fabricating evidence.

Test the production build and final public route at desktop, tablet, and mobile widths. Check console and network failures, HTTPS/mixed content, local logo/favicon URLs, anchors, phone/WhatsApp links, keyboard navigation, validation, submission loading/error/success states, back/refresh behavior, and duplicate conversion events. Do not submit a real LeadSquared lead without authorization. Save reproducible findings in `QA-REPORT.md`.
