# Design shotgun

Use only when the design direction is genuinely undecided.

Create three compact alternatives that differ in structure, hierarchy, typography, imagery treatment, and conversion flow, not merely colors. Render comparable desktop and mobile hero/first-two-section prototypes or static HTML previews. Label each direction, state the audience fit and tradeoffs, and recommend one. Do not build the full production site until a direction is selected. Record the selected direction in `DESIGN-DIRECTION.md` and preserve the rejected alternatives only as decision evidence.
