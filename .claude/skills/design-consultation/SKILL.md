# Design consultation

Use for a new landing page or a substantial redesign.

1. Inspect the supplied URL/files, screenshots, approved Finprov assets, audience, course facts, and conversion goal.
2. Write `DESIGN-DIRECTION.md` with the audience, one-sentence promise, visual language, typography, color tokens, spacing/radius rules, section order, imagery plan, motion policy, form placement, mobile behavior, and accessibility constraints.
3. Preserve verified facts and licensed brand assets. Treat the incumbent page as evidence, not as code or copy to clone.
4. Prefer a clear Finprov-specific direction over generic gradient, glass-card, centered-hero templates.
5. If the brief supports several materially different directions, route to `$design-shotgun`. Otherwise choose the strongest evidence-backed direction and proceed.
6. Do not invent placement numbers, accreditations, fees, deadlines, testimonials, or outcomes.

The deliverable is a concrete direction that another skill can implement without guessing.
