# Integration reference only

There is intentionally no index.html or page design. Generate original campaign HTML/CSS/source from the brief, then adapt the generic tracking.js, site-config.js and PHP endpoint after checking their contracts. Brand PNGs are included. This directory alone is not a runnable page or valid final release.

Existing connected sites must keep their actual API/configuration and tracking ownership. Do not copy these initial integration examples over live backend files. Initial release validation applies to the generated release, never this incomplete reference directory. `test_tracking.mjs` can still test the tracking contract without a page or network.
