# Image assets

Use an available image-generation tool only when the page needs a new non-evidentiary visual and the user permits generation. Never fabricate students, testimonials, placement posters, certificates, partner logos, results, or documentary evidence. Prefer approved Finprov photography and provided assets. If no generation tool exists, produce an asset brief with dimensions, aspect ratio, subject, treatment, alt text, and placeholder filename; do not pretend an image was generated. Optimize final images, include intrinsic dimensions, use responsive formats, and keep every shipped asset local when licensing permits.
