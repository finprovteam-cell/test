# Template contents

README.md and START-HERE.md are the human entrypoints. CLAUDE.md, AGENTS.md and MASTER-HANDOVER-FOR-CLAUDE.md guide AI work. `.claude/skills/` contains the 15 bundled skills including Impeccable and generic integration references; no campaign HTML/design source is included. BRAND-ASSETS supplies the logo/favicon. TECH-SETUP contains setup and departure handover references. `.devcontainer/` configures an optional remote Codespaces environment. `.github/workflows/toolkit-checks.yml` checks the toolkit only, with no deployment. INPUT/ and OUTPUT/ are empty placeholders.

New setup contract: TECH-SETUP/setup-request.example.json, server-policy.example.json, CPANEL-CLAUDE-SETUP.md and the setup-only skill with its read-only validator/tests. No server setup is automatically enabled.
